# JobKG — платформа поиска работы в Кыргызстане

Слоган: **Найди работу, которая подходит именно тебе.**
Чистые HTML + CSS + JavaScript, без фреймворков и платных библиотек. Интерфейс на русском и кыргызском.

> Это **демо-версия**. Вакансии и компании — вымышленные тестовые данные (везде помечены «Тестовые данные»). Отклики, вакансии и сообщения никуда не отправляются.

## Запуск на macOS

Сайт загружает данные из `data/*.json`, поэтому его нужно открывать через локальный сервер (двойной клик по `index.html` не подойдёт — браузер блокирует загрузку JSON).

**Вариант 1.** Двойной щелчок по `start-macos.command` (при первом запуске: правый клик → «Открыть»). Если не запускается:
```bash
cd путь/к/JobKG
chmod +x start-macos.command
./start-macos.command
```
**Вариант 2.**
```bash
cd путь/к/JobKG
python3 -m http.server 8000
# откройте http://localhost:8000
```
Нужен Python 3 (есть в Xcode Command Line Tools: `xcode-select --install`). Остановка — `Ctrl+C`.

## Как проверить
1. Запустите сервер, откройте `index.html`.
2. Поиск: введите «дизайнер» в главном блоке → откроется каталог с найденным. Фильтры и сортировка работают на данных каталога; состояние хранится в адресе (`?city=osh`).
3. Нажмите ♡ на карточке — счётчик в шапке растёт, список в «Избранное»; сохраняется в LocalStorage.
4. Переключите RU/KG — меняются тексты интерфейса, выбор запоминается.
5. Формы (отклик, вакансия, вход, регистрация, контакты) проверяют поля; при успехе явно сообщают, что данные **не отправлены**.
6. Проверьте телефон: DevTools → режим устройства (мобильное меню, выезжающие фильтры).

## Что реализовано
- Каталог: поиск по должности, компании, ключевым словам (с синонимами), фильтры (город, категория, зарплата от, тип занятости, опыт, формат), сортировка (дата, зарплата), сброс, счётчик, пустое состояние
- Карточки и страницы вакансий (обязанности, требования, условия, график, навыки, компания, похожие)
- Избранное (LocalStorage), каталог компаний с поиском и фильтрами, страницы компаний
- Подборки для студентов, статьи
- RU/KG через `i18n.js` (новый язык: добавить код и словарь)
- Адаптивность, мобильное меню, доступность (skip-link, ARIA, фокус, подписи форм), SEO-теги
- Безопасность: текст в DOM вставляется как текст (без `innerHTML` для данных), пароли и контакты не сохраняются

## Демонстрационное (работает, но без сервера)
- Тестовые вакансии/компании; форма отклика (проверка без отправки); форма вакансии (локальный черновик без контактов); кабинеты соискателя и работодателя (данные только в браузере; переключатель роли — не вход в аккаунт).

## Требует backend
Регистрация и безопасный вход, роли, хранение паролей и резюме; публикация и модерация вакансий; реальная отправка откликов и их просмотр; уведомления по email; оплата и тарифы. Авторизация на одном JavaScript/LocalStorage намеренно **не** сделана — она небезопасна.

## Переводы: что не переведено
Интерфейс переведён полностью. **Тексты вакансий, компаний и статей** (`data/*.json`) пока только на русском; на KG показывается пометка. Перевод стоит проверить носителем языка.

## План перехода к production
1. Backend (Node/NestJS, Django или Laravel) + PostgreSQL; REST API вместо `data/*.json` (замена в `JobKG.data` в `app.js`).
2. Аутентификация (сессии/JWT в httpOnly-cookie, хэширование паролей argon2/bcrypt, подтверждение email, сброс пароля), роли.
3. CRUD вакансий, модерация, отклики, загрузка резюме (антивирус, лимиты), уведомления.
4. Поиск: полнотекстовый (PostgreSQL FTS/Meilisearch), пагинация.
5. Юридическое: политика конфиденциальности, условия, согласие на обработку персональных данных (места в футере зарезервированы).
6. Монетизация: тарифы, платёжный провайдер, выделение вакансий.
7. SEO/инфраструктура: sitemap, robots, SSR/статическая генерация страниц вакансий, HTTPS, CSP, мониторинг, резервные копии, CI и автотесты.

## Тестирование
Автоматически (Playwright, Chromium) проверены: открытие всех страниц, отсутствие ошибок консоли и битых внутренних ссылок, горизонтальная прокрутка на 375 px, поиск, каждый фильтр, сортировка, сброс, избранное, смена языка, валидация форм, отсутствие хранения паролей/контактов. Не проверялись: Safari/Firefox, реальные телефоны, чтение скринридером.
